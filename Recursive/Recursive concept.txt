recursive : calling the same function with same algorithm

factorial = N * fact(N-1);

if N = 6;

6! = 
6 * fact(6 - 1) // hold ( not yet calculated ), call the function again
	       // now, N = 5;
5 * fact(5 - 1)

4 * fact(4 - 1)

3 * fact(3 - 1)

2 * fact(2 - 1)

fact(2 - 1) == 1, which means the N = 1;
because the base case is if N <= 1 then return 1,
thus, it's starting to calculate from the bottom function to top.

6 * 120 = 720
5 * 24 = 120
4 * 6 = 24
3 * 2 = 6
2 * 1 = 2

720 is the final result of factorial, recursive algorithm ends.

To be cleared, base case is a condition to stop a function calling the function itself.
If base case doesn't declared, then the function will create infinite loop since the function keep calling itself.
